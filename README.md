# NOVA COFFEE

Concept website for **NOVA COFFEE** — a specialty coffee roastery in Damascus.
Brand identity & web design by **Khaled Salami**.

موقع كونسبت لمحمصة **نوفا كوفي** — الهوية البصرية وتصميم الموقع: **خالد سلامي**.

## Features

- Bilingual: English / العربية (full RTL support)
- Light & dark themes (follows the device, with a manual toggle)
- Fully responsive, no frameworks, no build step
- Inline SVG logo and illustrations

## Structure

```
index.html        # page markup
css/style.css     # all styles
js/main.js        # language + theme toggles, smooth scroll
assets/favicon.svg
```

## Run locally

Just open `index.html` in a browser.

## Deploy with GitHub Pages

Repository → **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
The site will be live at `https://<username>.github.io/nova-coffee/`.
